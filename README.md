# Marioclub — Static Web Page

## Project Overview
**Marioclub** is a foundational frontend web development project built using pure **HTML5** and **CSS3**. Created as an early exercise in semantic markup and visual layout design, the page showcases structured page sections, positioned hero banners, multi-column navigation, and responsive media queries.

## Key Features
* **Semantic HTML5 Structure:** Organized layout utilizing `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, and `<footer>` elements (`index.html`).
* **CSS Positioning & Layout:** Implements fixed header navigation, relative/absolute hero banner overlays, and centered content typography (`marioclub.css`).
* **Interactive Form & Media Gallery:** Includes styled newsletter sign-up inputs, pseudo-class hover/focus states, and a visual image gallery (`img/`).
* **Responsive Breakpoints:** Adapts layout spacing and typography across desktop, tablet, and mobile viewports using CSS media queries.

## Project Structure
* **`index.html`:** Core HTML5 document defining page content, navigation links, and form structure.
* **`marioclub.css`:** Custom stylesheet handling layout positioning, typography, pseudo-classes, and responsive rules.
* **`img/`:** Banner graphics, character thumbnails, and page media assets.

## Tech Stack
* **Languages:** HTML5, CSS3
